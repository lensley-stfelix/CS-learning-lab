# Python Practice

This folder documents my progress learning Python through exercises,
experiments, and small projects.

## Folder guide

### `fundamentals/`

- `hello_world.py` — basic output
- `boolean_and_nested_conditionals.py` — Boolean expressions and nested decisions
- `nested_conditionals_and_exceptions.py` — conditionals and basic error handling
- `loops.py` — `while` loops, `for` loops, ranges, `break`, and `continue`
- `nested_loops.py` — matrices, grids, and nested iteration
- `collections_and_lists.py` — lists, slices, sets, tuples, dictionaries, and 2D lists
- `functions_and_recursion.py` — functions, return values, scope, recursion, and debugging

### `modules_and_files/`

- `modules_file_io_and_employee_records.py` — modules, file I/O, CSV data, and an employee-record exercise
- `temperature.py` — reusable temperature-conversion functions
- Supporting `.txt` and `.csv` files used by the exercises

### `object_oriented_programming/`

- `classes_inheritance_and_scope.py` — classes, objects, inheritance, methods, and scope
- `temperature.py` — supporting module from the class and module exercises

### `projects/`

- `drink_order.py` — nested-conditionals drink-order program
- `tic_tac_toe_basic.py` — first manually sequenced Tic-Tac-Toe version
- `tic_tac_toe_with_validation.py` — loop-based version with input and occupied-space validation
- `tic_tac_toe_final.py` — function-based version with win and tie detection
